# 关于与软件更新

## ADDED Requirements

### Requirement: 关于页面 SHALL 展示可核验的软件信息

应用 SHALL 提供独立的“关于”页面，展示软件名称、当前安装版本、运行平台与架构、稳定版发布渠道、开源许可证及项目 GitHub 链接。当前版本和运行环境信息 SHALL 来自应用元数据或运行时，不得用固定展示值代替。

#### Scenario: 查看当前软件信息

- **WHEN** 用户打开关于页面
- **THEN** 页面显示当前安装的软件名称、版本、平台、架构、稳定版渠道、许可证入口和项目仓库链接

### Requirement: 应用 SHALL 检查 GitHub 稳定版更新

应用进入已配置的主工作区时 SHALL 检查一次 Skill Sync GitHub Releases 中可安装的最新稳定版；关于页面 SHALL 提供手动重新检查入口。版本 SHALL 按语义版本比较，草稿和预发布版本不得作为可用更新。检查失败 SHALL 与“已是最新版本”明确区分，并允许重试。

#### Scenario: 启动时发现较新稳定版

- **WHEN** 已配置的主工作区启动且 GitHub 提供高于当前版本的正式版
- **THEN** 应用保存可用版本信息、发布说明和 release 链接供关于页面与导航共同显示

#### Scenario: 当前版本已是最新

- **WHEN** 检查成功且远端稳定版不高于当前安装版本
- **THEN** 关于页面显示已是最新版本，且主导航不显示更新标记

#### Scenario: 更新检查失败

- **WHEN** GitHub 请求失败、更新元数据无效或网络不可用
- **THEN** 关于页面显示检查失败及重试入口，不把失败解释为已是最新版本

#### Scenario: 手动重新检查

- **WHEN** 用户在关于页面发起检查
- **THEN** 应用重新请求当前平台的最新稳定版元数据，并更新页面及导航状态

### Requirement: 可用更新 SHALL 在导航和关于页面中明确呈现

存在高于当前版本的可安装稳定版时，主导航的“关于”入口右侧 SHALL 显示绿色圆形更新箭头；无更新或检查失败时 SHALL 不显示该标记。关于页面 SHALL 显示新旧版本、发布说明、发布时间（若发布元数据提供）和对应 GitHub Release 链接。

#### Scenario: 导航显示更新提示

- **WHEN** 更新检查确认存在可安装的新版本
- **THEN** “关于”导航项右侧显示绿色圆形更新箭头，且该提示可由无障碍名称识别

#### Scenario: 浏览更新详情

- **WHEN** 用户打开有新版本的关于页面
- **THEN** 页面显示当前版本、可用版本、发布说明、可用的发布时间和 GitHub Release 链接

#### Scenario: 更新提示清除

- **WHEN** 用户安装更新并重启进入新版本
- **THEN** 应用再次检查后不再显示旧版本的更新提示

### Requirement: 更新安装 SHALL 校验签名并由用户发起

应用 SHALL 分别由用户显式发起下载和确认安装；Tauri updater SHALL 使用应用内公钥校验 GitHub 发布的更新签名。应用 SHALL 展示下载进度，下载并验证成功后才允许确认安装。Windows 确认安装后 SHALL 明确提示会关闭应用并启动安装器，安装器完成后重新打开应用；macOS 安装成功后 SHALL 提供立即重启入口，允许稍后重启。应用不得自动安装更新或绕过签名校验；正在执行同步或恢复时 SHALL 阻止安装与重启。

#### Scenario: 用户安装可用更新

- **WHEN** 用户在关于页面下载检测到的稳定版更新并通过签名验证
- **THEN** 页面显示更新已就绪与安装入口，只有确认安装后才执行平台安装操作

#### Scenario: Windows 确认安装

- **WHEN** Windows 用户确认安装已验证的更新包
- **THEN** 应用明确告知会退出并启动安装器，在同步或恢复操作完成后才允许继续

#### Scenario: macOS 安装完成

- **WHEN** macOS 用户安装更新成功
- **THEN** 页面显示安装完成和立即重启入口，且允许用户稍后重启

#### Scenario: 更新签名无效

- **WHEN** 更新包签名校验失败
- **THEN** 应用拒绝安装、显示可理解的错误并保留当前已安装版本

#### Scenario: 更新下载或安装失败

- **WHEN** 更新下载中断或安装过程失败
- **THEN** 应用显示失败状态和重试操作，不显示安装成功或要求用户切换到未验证的安装包

#### Scenario: 用户取消或暂不重启

- **WHEN** 用户下载后取消安装确认，或 macOS 更新安装后选择暂不重启
- **THEN** 应用保持当前运行状态，不在后台自动执行后续更新步骤
